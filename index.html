AI model for the tab

Chat models do not process audio. DeepSeek, Claude and local LLMs only choose tab fingerings. They cannot cut or improve the guitar or bass track, and they never receive the song.

Cutting the instrument and writing the first tab always run on this PC with the audio model Demucs. The chosen AI only refines the visible part of the tab when you press Improve with AI; nothing is sent otherwise.

A Claude chat subscription does not include API access; Claude needs an Anthropic API key. The last option works with any OpenAI-compatible API, local or cloud: Ollama, LM Studio, DeepSeek, OpenAI, OpenRouter, Groq, Mistral. Paste a base URL such as https://api.deepseek.com, https://api.openai.com or https://openrouter.ai/api/v1, or a full /chat/completions URL. Use the model ID from the provider, not its display name; cloud APIs need the key from that provider.

Separation model

Only an audio separation model can cut a stem. Cloud chat models such as DeepSeek or Claude cannot do this. The list shows Demucs models installed on this computer. htdemucs_6s is the included default and the only one with a guitar stem.
